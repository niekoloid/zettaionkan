# いろおと 20秒ショート動画 絵コンテ(自前撮影用)

目的: TikTok / Instagram リール / YouTube ショートで「色でピアノの和音を覚える」が一目で伝わる動画を、まず自分で5本撮って反応を見る。外注はその後。

## 共通ルール

- 縦 9:16、20秒以内。最初の1秒で「色の丸が光る」か「子どもの手が伸びる」を見せる(スクロールを止めるのはこの2つ)。
- 音なしで見られても分かるよう、字幕を必ず入れる。ただし音が主役なので「🔊 音を出して」の表示を冒頭に。
- 子どもの顔は映さない(手・後ろ姿・横顔の一部まで)。本人の安全と、後で削除したくなった時の負担を減らすため。撮り直しもしやすい。
- 画面は iPad を机に置いて真上から、または床に置いて斜め上から。スマホより iPad のほうがボタンが大きく映る。
- アプリ側の準備(2026-10 の作り直し後): 画面で子どもが色ボタンを押す仕組みはなくなり、子どもは**机や床に並べた色の丸(印刷用の「いろマット」 `/mat`)にタッチし、親が○を押す**流れになった。「色のボタンを押す」カットは「いろマットの色の丸にタッチする手」に置き換える。背景が和音の色に変わるカットは「きく」画面(`/listen`)で撮れる。レッスン画面は親の手元(○×と「こたえ」)を映す。
- 終わりは必ず同じ1枚: 「いろおと|無料で始める」+ プロフィールのリンクへ誘導。
- 計測: プロフィールのリンクは `https://zettaionkan.jp/?utm_source=tiktok&utm_medium=social&utm_campaign=ugc01`(`/lp` は作り直しで廃止したのでトップページへ) のように動画ごとに変える。

## 案1: 「光った色を探す」(先方の案に近い・本命)

| 秒 | 映像 | 音 | 字幕 |
|---|---|---|---|
| 0–2 | 画面いっぱいに赤の丸。子どもの指がタップ、画面全体が赤に染まる | ドミソ | 「音に、色があるの知ってた?」 |
| 2–6 | 真上から。14色のボタン。子どもの手が迷いながら黄色へ | タップ音 → ドファラ | 「きいろは、ドファラ」 |
| 6–12 | 和音クイズ画面。音が鳴る → 子どもの手が止まる → 青へ | シレソ → 正解音 | 「音だけで、色がわかる」 |
| 12–17 | 正解でキャラ(ねこ)が反応。子どもが親の方へ振り向く(後ろ姿) | 正解音 + 子どもの声(あってもなくても) | 「2歳からの絶対音感トレーニング」 |
| 17–20 | 終わり画面 | — | 「いろおと|無料で始める」 |

## 公開の順番と見方

1. 案1と案3を先に出す(本命と、手間が少ないもの)。
2. 1週間で、再生数より「プロフィールのリンクがどれだけ押されたか」と、LP の `utm_campaign` 別の登録数を見る。
3. 伸びた型だけ、撮り方を変えて3本追加。
4. ここで初めて「外注するか」を決める。外注する場合は、伸びた案の絵コンテをそのまま渡せば、企画費が浮く。

## 法律・配慮

- 自分の子どもでも、将来の本人の意思を考えて顔は出さない方針を勧める。
- 「絶対音感が身につく」とは言わない。「トレーニング」「耳を育てる」まで。
- 音楽の著作権: アプリの和音音源のみ使い、流行曲の BGM は乗せない(乗せると商用利用の規約に触れる場合がある)。
